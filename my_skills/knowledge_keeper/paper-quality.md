# 论文质量判断（knowledge_keeper 参考文件）

判断一篇论文值不值得跟，而不是只判断它相不相关。本文件只在 `knowledge_keeper` 需要做论文级质量判断时加载。

## 1. 三个独立字段，不合成总分

| 字段 | 取值 | 回答的问题 |
|---|---|---|
| 角色 | anchor / competitor / adjacent / background | 它在本课题里承担什么作用 |
| 质量 | strong / usable / weak / unassessed | 它本身能信到什么程度 |
| 阅读深度 | metadata / abstract / full / code / reproduced | 当前判断基于读了多少 |

角色：anchor=主要跟随对象（问题定义或实验/理论标准的来源）；competitor=直接竞争的先例；adjacent=高质量相邻工作；background=背景资料。

质量判断必须记录更新时间和依据，允许随阅读深入而改变：读了全文、查了代码、看到独立复现后，结论可以改，写明旧判断为何失效。

## 2. 三层判断，顺序执行

### 第一层：是否真的相关

- 研究的是不是同一个问题、相近的条件和数据？
- 核心结论是否与本课题冲突？
- 解决的是核心问题，还是只是术语相似？

标题、关键词或方法名相似，不足以算直接工作。

### 第二层：论文自身站不站得住

- **想法**：能否用一句直白的话说清它发现了什么、为何有效。只会"堆模块涨点"、说不出新理解的，不能当 anchor。
- **证据**：对照够不够强、比较是否公平、关键组件是否单独验证、是否只在特殊设置成立、是否报告波动和失败、论文声称的原因是否被实验或理论直接支持。
- **理论**：有公式不等于有理论价值。定理是否对应核心问题、假设是否合理、是否比直觉更进一步、能否解释现象或给出可检验预测。
- **可检查性**：方法描述、数据、评价协议是否完整，有无代码或独立复现。不单独决定质量，但影响可信度。

### 第三层：外部信号（辅助，不能覆盖第二层）

- **会议/期刊/CCF 等级**：决定优先阅读顺序和该领域的通行实验标准；顶会顶刊也可能证据不足，预印本不等于弱。
- **作者**：不看"名气"，看该作者或团队是否长期在这个具体问题上做出可靠工作；用于筛选优先阅读对象和追溯关键工作链。
- **引用与后续影响**：记录查询日期并考虑发表时间；重点看是否被独立团队采用、是否成为常用对照、结论是否经受住后续检验。

## 3. 结论模板（写进论文笔记）

```text
结论：anchor / competitor / adjacent / background + 是否值得依赖
原因：最有价值的一点、证据是否足够、最大的问题、判断基于的阅读深度
用法：跟它的问题定义 / 跟它的实验标准 / 与它比较 / 仅作背景
```

## 4. "占坑但做得差"的判定

| 已有工作情况 | 处理 |
|---|---|
| 同一问题、同一核心想法、证据扎实、范围完整 | 高度冲突，上报 research_progress 考虑转向 |
| 同一问题，但想法弱、实验不充分或理论站不住 | 记为 competitor，写明差在哪；不据此否定课题 |
| 质量高但只解决相邻问题 | 记为 anchor/adjacent，不算占坑 |
| 只在标题或术语上相关 | 记为 background |

"别人做得差"本身不是贡献。若要在同题上做，必须能说出我们额外提供什么：更清楚的机制、更可信的证据、更广的适用范围、新理论，或对原结论的系统反证。
