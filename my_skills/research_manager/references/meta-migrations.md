# 元目录版本与迁移

元目录（`.kilo/`）的结构版本。版本标记在 `global.md` frontmatter 的 `meta_version`；无标记视为 v1。

## 版本表

| 版本 | 结构 | 说明 |
|---|---|---|
| v1 | `global.md` + `TODO.md` + `proposal/` + `project/` + `archive/` + `reports/` + `knowledge/`（research_manager §1） | 2026-10-08 补记，现行结构 |

## 迁移步骤怎么写

每个新版本在这里加一节 `vN → vN+1`，固定四块：

1. **检测**：什么特征说明元目录还是 vN（缺哪个文件、目录名是什么）。
2. **差异**：vN 和 vN+1 的结构对照（哪个目录改名、哪个文件新增）。
3. **步骤**：按序执行的搬动/新建/改名，每步一条。
4. **验证**：迁移完成后检查什么（链接能解析、TODO 能读、各技能找得到入口）。

## 迁移纪律

- 先出迁移计划，用户确认后执行；计划里写清每步动什么。
- 只加不删：旧文件先搬到新位置，验证通过后删除走 research_manager §8 的清理流程，不在迁移里顺手删。
- 迁移完成后更新 `global.md` 的 `meta_version`。
