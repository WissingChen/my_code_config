# 分节指南：Abstract

写或改摘要时加载。场景文件的句式模板（如 ICLR 基准七句式）优先于本文件的通用模板。

## 动笔前四个问题

1. 解决什么问题，为什么没有现成答案？
2. 技术贡献是什么？
3. 为什么本质上可行？
4. 带来什么优势和新的认知？

## 三个通用模板（选一）

1. **挑战 → 贡献**：任务一句 → 前人挑战一句 → 贡献一两句（只报名字和核心属性，不展开步骤）→ 优势 → 实验结果。
2. **挑战 → 洞见 → 贡献**：中间多一句洞见，贡献句说明洞见如何被实现。
3. **多贡献**：每个贡献一句"贡献 + 优势"，一句一贡献。

## 自查

- 一遍读下来能否指出任务、挑战、贡献、结果？
- 每个声明有实验证据吗？
- 技术名词自含吗（读者不需要跳正文）？
- 有没有一句话塞了两件事？
