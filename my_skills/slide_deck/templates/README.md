## 模板文件夹结构

- `STYLE.md` — 风格规范：风格 DNA、色板 token、布局数值、组件清单、图标库、QA 坑点记录。
- `template.html` — 可渲染的基准实例（单页自包含 HTML）。复刻时复制其中的 CSS 块与 HTML 骨架，只替换内容。

## 维护规则

1. **使用**：用户点名某风格时，先读对应 `STYLE.md`，按其风格 DNA、色彩语义与布局模式库**参考风格、按内容选型**；`template.html` 只是其中一种模式的实例，不是必须复刻的骨架。不凭记忆重写样式。
2. **新增**：从已通过视觉 QA 的 slide 中提取 CSS 变量与组件骨架 → 新建 `templates/<风格名>/STYLE.md` + `template.html` → 在本索引登记（风格名、适用场景、来源实例、日期）。
3. **修订**：风格的改进回写到模板文件（单一事实源），并更新索引中的日期；套用页面只改内容，不改 token 定义。
4. **QA**：每次新增或修订模板后，必须用 headless Chromium 截图检查 `template.html`（1600×900），把新发现的坑写进 `STYLE.md` 的 QA 记录。
