# 国自然基金风格（NSFC Figure Style）

基金申请书技术路线/研究方案插图的通用视觉语言。本文件是**风格规范**，不是单一骨架：布局按内容拓扑从 §2 模式库选择或组合，`template.html` 只是模式 A 的一个已通过 QA 的实例。禁止不看内容硬套三段式。

- 来源实例：`room2manip/slides/index.html` slide 12（模式 A，2026-08-13 通过视觉 QA）
- 风格参照 case（2026-08-15 用户提供，具身智能基金申请书）：
  - 图 3 总体研究方案：中央分层栈 + 左右编号虚线面板 + 底部横向大面板（模式 B）
  - 图 4 技术框图：总标题条 → 三分支 → 内容面板 → 总结条 → 科学问题 pill（模式 C）
  - 图 5 重建推理流程：虚线面板横向串联 + 梯形变换 + 照片红圈黄箭头标注（模式 D）
  - 图 7 零样本泛化：左右双域实线框 + 顶部粗蓝箭头 + 虚线能力集 chip（模式 E）

## 1. 风格 DNA（识别特征，缺一就不像）

1. **面板容器语法**：虚线边框面板 = 研究内容/阶段的边界分组；实线细边圆角框 = 子模块；浅色填充 = 语义分层。三层嵌套（虚线面板 > 实线框 > 小 chip）表达层级，不靠字号堆叠。
2. **编号标题**：面板级标题用「1. ×××」「2. ×××」粗黑体，置于面板上方或内顶；同层级标题样式必须一致。
3. **粗块状箭头**：实心色块箭头（非细线、非文字 →）连接面板与模块；颜色随语义（蓝=主数据流，灰=结构连接，橙=生成/回路，绿=反馈，黄=注意力标注）；双向粗箭头 = 交互/闭环。
4. **红色强调**：关键科学问题/研究目标用红色粗字（可带 ✓），放在对应模块内部下方；红色只用于此，不做装饰。
5. **混合媒体**：机制、算子、变换用手绘 SVG 图标；感知对象、真实场景、实验截图用真实照片，照片上叠加红圈 / 黄箭头标注关注点。纯图标拼贴反而不像。
6. **收束条**：每个大面板底部可用浅蓝灰圆角条写一行机制总结；下方可挂蓝色 pill 小标签标注「科学问题一、三」等归属。
7. **图题**：图下方居中「图 N. 标题」，与正文图注格式一致。

## 2. 布局模式库（按内容拓扑选择，可同页组合）

| 模式 | 内容拓扑 | 结构 | 参照 |
|---|---|---|---|
| A 三段式 pipeline | 输入→引擎→输出 + 闭环 | 三栏横向 + 橙色块状箭头 + 胶囊横幅 | template.html |
| B 分层栈 + 侧翼 | 总体技术路线、多层级体系 | 中央纵向 pastel 圆角框栈（下层→上层粗蓝箭头上行，每层内嵌红色✓目标），左右编号虚线面板，底部横向虚线大面板（可含循环图） | 图 3 |
| C 总-分树 | 一个方向拆成 N 个研究内容 | 顶部灰底圆角总标题条 → N 个白底圆角分支标题框 → 各挂内容面板（内部流程自由）→ 浅蓝灰总结条 → 科学问题 pill | 图 4 |
| D 横向流水 | 单一流程/管线细化 | 虚线面板横向串联，面板底部粗体标签；内部梯形/漏斗变换符 + 白色圆角算子框 + 灰色步骤 chip（内嵌彩色关键词）+ 照片标注 | 图 5 |
| E 双域迁移 | 源域→目标域、泛化、对比 | 左右两大实线圆角框，顶部粗蓝箭头 + 文字标注迁移关系；虚线框表能力集合（内部小青 chip）；黄色高亮框标关键步骤 | 图 7 |

选型原则：先问内容的拓扑是什么（分层？分解？流水线？迁移？生成闭环？），再选模式；一张 slide 可以是「模式 C 挂三个模式 D 面板」这类组合。

## 3. 色板（CSS tokens）

```css
/* 语义填充（pastel，模式 B/C/E 的分层与 chip 用色） */
--fig-navy: #1f3a63;        /* 标题栏、归因色块1、强调文字 */
--fig-blue: #2e6fb7;        /* 编号圆圈、步骤边框、主数据流箭头 */
--fig-blue-soft: #eaf2fb;   /* 步骤框底色 */
--fig-blue-line: #c2d6ee;   /* 引擎面板边框 */
--fig-green: #5f9e46;       /* 感知/输入语义、反馈箭头 */
--fig-green-deep: #3f6f2f;
--fig-green-soft: #eff7e7;
--fig-green-line: #c2dfae;
--fig-orange: #e8833a;      /* 生成/回路箭头、标签 */
--fig-gray: #59637a;        /* 过程/算子框、结构连接箭头 */
/* case 收敛新增 */
--fig-cream: #fbf3d9;       /* 规划层/关键步骤填充（图3 具身规划） */
--fig-cyan-soft: #d9eef2;   /* 能力 chip 填充（图7 习得感知能力） */
--fig-panel-gray: #f2f2f2;  /* 总标题条、过程框灰底 */
--fig-red: #c00000;         /* 关键科学问题/目标强调（仅文字与✓） */
--fig-yellow-hl: #fff2cc;   /* 关键步骤高亮框（图7 空间因果建立） */
```

副条件栏底色 `#dce7f6`；归因面板边框 `#c9cfdb`；总结条底色 `#e8eef7`。依赖宿主 deck 的基础 token：`--ink`、`--muted`、`--line`。

填充色=语义：绿=感知/输入，黄/cream=规划/关键，蓝=控制/输出/主流程，灰=过程/算子，青=能力/标签。同一 slide 内同一语义必须用同一色。

## 4. 布局数值（模式 A 基准；其他模式按比例推演）

- 模式 A 三栏 flex：左栏 300px / 右栏 348px / 箭头栏 62px / gap 12px；引擎栏 `flex:1`。
- 字号层级：面板编号标题 20–21px/800 → 模块标题 18.5–19px → 副栏 16.5px → 正文 14.5–15px → 小标签 12.5–13.5px → 横幅 19px。
- 步骤框内部：`hd`（编号圆圈 26px + 标题）+ `bd`（32px 图标 + ≤3 行正文）。
- 模式 B 分层栈：层框宽约为中央栏 80%，层间距由上行箭头占 28–36px；红色✓目标行 15–16px。
- 模式 C 分支：N 分支等宽 flex，分支标题框与内容面板间距 12px，总结条与 pill 居中。
- 面板圆角 8–10px；虚线 `2px dashed`，实线 1.5px。

## 5. 组件骨架与图标库

模式 A 全部骨架见 `template.html`：`.syn` → `.syn-inputs` / `.syn-engine` / `.syn-attr` + `.syn-arrow` + `.syn-banner`。复制时连同 `:root` 中 `--fig-*` token 一起搬运。

图标（template.html 已有实现，可复用）：clipboard、floorplan、robot-arm、overlap-circles、shield-check、trajectory、split-node、refresh、database、layers、block-arrow。

手绘图标规范：`viewBox="0 0 24 24"`、`fill="none"`、`stroke="currentColor"`、`stroke-width="1.8"`、round caps/joins；不用 emoji。照片类素材用 `<img>` base64，标注用绝对定位的红圈（`border:2.5px solid #c00000; border-radius:50%`）与黄色小箭头。

## 6. QA 坑点记录（实测踩过）

- 箭头栏标签 **≤4 字**（15px 下 62px 栏宽），5 字必换行。
- 步骤内小签（`.syn-mini`）每签 ≤3 字，`font-size:12.5px` + `white-space:nowrap`。
- 副条件栏 / 归因副标题一句话写完，避免带括号的长注释。
- 步骤正文 ≤22 字（约 3 行 @153px 宽）：grid 行高由该行最高步骤框决定，一个框 5 行会拖累同排其他框出现内部死区。
- 归因面板公式用衬线字体与正文区分；下标用 `<sub>`。
- 横幅 `align-self:center` + `flex:0 0 auto`，不要拉伸整行。
- 红色只给关键问题/目标文字；红字超过两行就失去强调作用，拆回黑字。
- 照片标注的红圈/黄箭头数量 ≤3 处/张，多了像 PPT 涂鸦。
- 同页混用模式时，面板编号标题的字号字重必须全局一致，否则树形层级读不出来。
